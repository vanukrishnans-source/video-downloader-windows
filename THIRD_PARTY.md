# Third-party components

| Component | License | Use |
|---|---|---|
| yt-dlp (+ yt-dlp-ejs) | Unlicense | reads video pages and downloads the streams |
| FFmpeg / FFprobe (BtbN win64 LGPL shared build) | LGPL-2.1+ | merges video + audio into MP4, HLS, MP3/M4A, checks files |
| QuickJS-ng | MIT | small JavaScript engine yt-dlp needs for YouTube |
| Qt for Python (PySide6-Essentials) / Qt 6 | LGPL-3.0 | user interface |
| pycryptodomex, mutagen, brotli, websockets, certifi, requests, urllib3 | BSD / GPL-2+ (mutagen) / MIT / MPL-2.0 / Apache-2.0 | yt-dlp helpers |
| PyInstaller | GPL-2.0 with bootloader exception | packaging |

FFmpeg source: https://github.com/BtbN/FFmpeg-Builds . QuickJS-ng source: https://github.com/quickjs-ng/quickjs .
